# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 3.x     | Yes |
| 2.x     | Security fixes only |
| 1.x     | No |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use [GitHub private vulnerability reporting](https://github.com/anhquoctran/FuzzyToast/security/advisories/new) so we can assess and patch before disclosure.

Include:

- FuzzyToast version
- .NET / Windows version
- A minimal reproduction
- Impact (for example: unexpected focus steal, local file/image handling)

You should hear back within **7 days**. We will coordinate a fix and a `CHANGELOG` note for the patched release.
